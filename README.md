# Tema 2 · Apuntes visuales

Apuntes visuales del Tema 2 (Información, documentos y análisis del dominio), corregidos y rediseñados.

- **[Tema2_apuntes_visuales_mejorado.pdf](Tema2_apuntes_visuales_mejorado.pdf)**: el documento final (41 páginas, A4).
- `fuentes/`: archivos para regenerarlo.
  - `build.py`: contenido y diagramas (SVG generados en Python).
  - `style.css`: diseño de página.
  - `tema2_apuntes_visuales.html`: HTML generado; se imprime a PDF desde Chrome (Imprimir → Guardar como PDF, A4, sin márgenes, con gráficos de fondo).

Para regenerar el HTML: `python3 fuentes/build.py`
